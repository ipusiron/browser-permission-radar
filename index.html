座学：ブラウザ権限の基礎

  • Permissions API は統一仕様だが、ブラウザごとに対応状況が異なる。
  • ユーザーが一度許可した権限は、そのオリジンに紐づく。
  • 一部の権限はユーザー操作（クリック）無しではリクエストできない（クリップボード等）。
  • 権限は最小限にとどめ、不要になれば速やかに停止・破棄する（例：getUserMediaの停止）。

権限の永続性について

  • 永続的な権限：通知（Notifications）・位置情報（Geolocation）・クリップボード書き込み等は、一度許可するとgranted状態が保持される。レーダーチャートの変化を確認するには、通知権限のテストを推奨。
  • 一時的な権限：カメラ・マイクはgetUserMedia()で許可されるが、ストリーム停止後はpromptに戻る。これはブラウザの仕様であり、プライバシー保護のための設計。
  • 状態の確認：Quick Testsで権限を許可した後、Rescan Allボタンでレーダーチャートを更新し、状態変化を観察できる。
